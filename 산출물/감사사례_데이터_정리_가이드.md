# 감사사례 데이터 정리 가이드

알리오에서 감사결과 파일을 받는 것부터 앱에 넣기까지의 순서예요. 이번에는 **물품 구매계약** 분야만 정리해요.

> ⚠️ 이 가이드를 만든 AI는 알리오 사이트에 접속하지 못해서, 알리오 안의 메뉴 이름은 직접 확인하지 못했어요. 메뉴 이름이 조금 다르면 비슷한 이름을 찾아 주세요.
>
> 💡 **11/25 확인:** 알리오 첫 화면의 **'감사원/주무부처 지적사항'** 메뉴(`alio.go.kr/occasional/auditPointList.do`)에서 기관을 고르지 않고도 여러 기관의 지적사항을 제목으로 한꺼번에 검색할 수 있어요. (예: 수의계약, 구매, 입찰, 검수, 지체상금) 게시글 주소는 `https://www.alio.go.kr/occasional/auditPointDtl.do?seq=번호` 형식이에요. 한글(hwp)만 있는 건보다 PDF가 있는 건이 정리하기 쉬워요.

---

## 1단계. 알리오에서 감사결과 찾기

1. [alio.go.kr](https://www.alio.go.kr)에 접속해요.
2. 기관을 검색하거나 기관 목록에서 하나를 골라요.
   - 사업이 많고 계약 건이 많은 공기업·공단이 사례가 풍부해요.
3. 그 기관의 공시 항목 중 감사 관련 메뉴를 찾아요.
   - 보통 '자체감사 결과', '감사원 감사결과', '주무부처 감사결과' 같은 이름이에요.
4. 게시글 목록에서 최근 2~3년 것을 열고, 첨부된 PDF를 받아요.
5. 게시글 주소(URL)를 복사해 두세요. 나중에 '출처링크' 칸에 넣어요.

**고르는 요령**
- 제목에 계약, 구매, 용역, 검수, 대금 같은 단어가 있으면 계약 분야 사례일 가능성이 높아요.
- 기관을 **5~8곳 정도로 섞어** 주세요. "여러 기관이 같은 실수를 했다"는 장면을 만들려면 기관이 다양해야 해요.
- 한글 파일만 있으면 한글에서 PDF로 저장해서 써요.

**파일 보관:** 원문 파일은 GitHub에 올리지 말고 팀 구글 드라이브 공유 폴더에 모아요. 파일 이름은 `기관명_연도_제목.pdf`로 통일해요.

---

## 2단계. PDF에서 지적사항 찾기

감사결과 문서 하나에는 지적사항이 여러 건 들어 있어요. **지적사항 1건이 시트 1줄**이에요.

보통 지적사항마다 이런 덩어리가 반복돼요(기관마다 표현은 조금씩 달라요).
- **제목:** "물품구매 계약 업무 처리 부적정" 같은 한 줄
- **내용 / 현황 / 문제점:** 무슨 일이 있었고 무엇이 규정에 어긋났는지
- **조치할 사항 / 처분:** 주의, 시정, 경고 등

이 중 **계약 분야 지적사항만** 골라서 정리해요. 복무, 인사 같은 건 이번엔 건너뛰어요.

---

## 3단계. 시트에 정리하기

구글 시트의 첫 줄 머리글은 [시트 양식](감사사례_시트_양식.csv)과 똑같이 만들어요.

```
검수상태 | 검수메모 | 사례ID | 원본파일 | 기관명 | 연도 | 업무분야 | 업무단계 | 지적유형 | 지적제목 | 지적요약 | 원인 | 관련규정 | 처분 | 근거문장 | 자동검사결과 | 출처링크
```

### 칸별 작성법

| 칸 | 쓰는 법 | 필수 |
|---|---|---|
| 검수상태 | 처음엔 비워 두고, 검수가 끝나면 `확인완료` | |
| 검수메모 | 검수하며 남길 말 | |
| 사례ID | `C001`, `C002`… 순서대로 (번호대 나누기: 예림 C001~, 유진 C101~, 주은 C201~) | ✅ |
| 원본파일 | 드라이브에 저장한 파일 이름 | |
| 기관명 / 연도 | 감사받은 기관, 감사 연도 | ✅ |
| 업무분야 | 이번엔 전부 `계약` | ✅ |
| 업무단계 | 아래 표에서 하나 골라요 | ✅ |
| 지적유형 | `절차 위반` `규정 미준수` `관리 소홀` `부당 집행` `과다·과소 지급` `기타` 중 하나 | |
| 지적제목 | 문서의 제목 그대로 | ✅ |
| 지적요약 | 무엇을 했는데 무엇이 문제였는지 1~2문장. 사용자가 입력할 말과 비슷한 쉬운 표현일수록 검색이 잘 돼요 | ✅ |
| 원인 | 문서에 원인이 적혀 있을 때만 | |
| 관련규정 | 문서에 나온 법령·규정 이름 | |
| 처분 | `주의` `경고` `시정` `징계` `변상` `개선` `통보` `권고` 중 하나 | |
| 근거문장 | 요약의 근거가 되는 원문 문장을 그대로 복사 | ✅ |
| 자동검사결과 | 비워 둬요 (앱이 채워요) | |
| 출처링크 | 알리오 게시글 주소 | ✅ |

### 업무단계 고르는 기준

| 업무단계 | 이럴 때 | 예시 |
|---|---|---|
| 계획 | 사기 전에 필요성, 예산, 방법을 정할 때 | 수요조사 없이 구매 추진 |
| 선정·심사 | 업체를 고르고 견적·입찰을 받을 때 | 견적 1곳만 받음, 분할 수의계약 |
| 계약·체결 | 계약서를 쓰고 조건을 정할 때 | 계약서 없이 납품 시작 |
| 집행·이행 | 계약대로 진행되는지 관리할 때 | 용역 인원 투입 확인 안 함 |
| 검수·확인 | 납품물을 확인할 때 | 검수조서 미작성 |
| 정산·지급 | 대금을 지급할 때 | 지체상금 미부과 |
| 사후관리 | 끝난 뒤 하자·보증을 관리할 때 | 하자보수 기간 점검 누락 |

### 한 줄 예시 (가상)

| 칸 | 내용 |
|---|---|
| 사례ID | C001 |
| 기관명 / 연도 | ○○공사 / 2025 |
| 업무분야 / 업무단계 | 계약 / 선정·심사 |
| 지적유형 / 처분 | 절차 위반 / 주의 |
| 지적제목 | 물품구매 수의계약 부적정 |
| 지적요약 | 수의계약 한도를 넘는 물품을 두 건으로 나눠 각각 수의계약을 체결함 |
| 근거문장 | (원문에서 복사한 문장) |
| 출처링크 | (알리오 게시글 주소) |

---

## 4단계. AI로 빠르게 정리하기

AI 채팅에 PDF를 올리고 위 칸에 맞춰 정리해 달라고 하면, 시트에 바로 붙일 수 있는 줄이 나와요. 다만 **AI가 만든 줄은 반드시 원문과 대조해서** 확인하고, 확인이 끝나면 검수상태를 `확인완료`로 바꿔요. 특히 근거문장은 원문에 정말 있는 문장인지 꼭 확인해요.

---

## 5단계. 앱에 넣기

1. 구글 시트 → 파일 → 다운로드 → 쉼표로 구분된 값(.csv)
2. 받은 파일 이름을 `cases.csv`로 바꿔서 앱 폴더의 `data/` 안에 넣어요.
3. 앱을 새로고침하면 사이드바의 '가상 예시 데이터' 경고가 사라지고 사례 수가 바뀌어요.

> 주의: 시트를 엑셀로 열었다 저장하면 한글이 깨질 수 있어요. 구글 시트에서 바로 CSV로 받는 걸 추천해요.
