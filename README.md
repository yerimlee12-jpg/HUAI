## 작업 규칙

1. 작업을 시작하기 전에 **항상 먼저 받아오기**(pull)를 해요.
2. 작업은 **조금씩 자주 커밋**해요. 커밋 메시지에는 무엇을 했는지 적어요.
   예: `회의록: 11/22 주제 선정 회의`
3. 각자 **자기 GitHub 계정으로** 커밋해요. 그래야 기여도가 기록에 남아요.
4. 할 일과 역할 분담은 **Issues** 탭에서 관리해요.
